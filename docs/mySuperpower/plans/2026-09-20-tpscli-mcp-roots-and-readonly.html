Overview

Goal: the MCP server's root folders can be replaced while it runs (tps_set_roots), tps_list_files lists any folder with or without roots (NO_ROOT retired), DESCRIBE and SELECT open the file ReadOnly so a read leaves its modified time alone, and a tagged push produces a zip on a GitHub Release that installs by unzipping.

Architecture: the CLI change is one method (tpsSchema.Open gains a writing flag) and two call sites. The server keeps its roots as its own state inside createServer, copied from the Config at construction, so a setter tool and the resolver share one array and the caller's config is never written back. Folder validation and the filesystem-exception guard are two small closures shared by tps_set_roots and tps_list_files. The release is one PowerShell script (tools\release.ps1: cli\verify.ps1, npm ci/build/test, stage, zip) that a workflow on a self-hosted Windows runner calls when a v* tag is pushed; the same script runs by hand.

Tech stack: Clarion 12.0.14000 (cli/), Node 20 + TypeScript 5 + @modelcontextprotocol/sdk 1.30 + zod 3.25 (mcp/), Windows PowerShell 5.1 for the scripts, gh 2.101 and GitHub Actions for the release. No new dependency.
