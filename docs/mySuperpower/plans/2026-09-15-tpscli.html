Overview

Goal: ship tpscli.exe, one static exe that takes a SQL statement, reads the table layout out of the named .TPS file, and runs DESCRIBE, SELECT, INSERT, UPDATE or DELETE through the real TopSpeed driver.

Architecture: four Clarion units behind one main. tpsSchema parses the TPS binary definition record and builds a runtime FILE with SoftVelocity's DynFile class. tpsSql tokenizes and parses the SQL subset into a statement record whose WHERE is a Clarion expression over the file's own bound field labels. tpsExec walks the file with SET/NEXT on a chosen key, filters with EVALUATE, and writes with ADD/PUT/DELETE inside LOGOUT/COMMIT. tpsOut writes JSON or a text grid to the inherited stdout handle. A generated corpus with a DynFile "oracle" dump is the test bed for every unit.

Tech stack: Clarion 12.0.14000 (C:\Clarion12), MSBuild 4.0, a CUI module-definition file, DynFile (libsrc\win\DynFile.inc, source-linked), CapeSoft StringTheory 3.82 (source-linked from accessory\libsrc\win), TopSpeed driver static (ClaTPSl.lib), Dynamic File Driver static (ClaDFl.lib), Win32 GetStdHandle/WriteFile/ReadFile, PowerShell for verify.ps1.

Global constraints (from the spec)

  • One statement per invocation. SQL from the first positional argument, else stdin.
  • Table names are bracketed paths: [C:\dir\FILE.TPS]. Bare names are relative to the current directory.
  • Output is JSON on stdout, always ending with "complete": true. --table renders a grid. Diagnostics only on stderr.
  • Exit codes: 0 ok, 1 syntax/validation, 2 file/definition, 3 runtime. Error codes exactly as spec §8, plus outcome on write failures.
  • File opened with SHARE(). HOLD(file,1). No retries. UPDATE and DELETE refuse a missing WHERE and any LIMIT/OFFSET.
  • Unknown field type or unreadable definition fails the open. Driver error 47 is DEFINITION_MISMATCH.
  • DATE out as YYYY-MM-DD, TIME as HH:MM:SS.hh, DECIMAL as an exact string, BLOB as base64. String overflow truncates with a STRING_TRUNCATED warning; every other conversion failure is VALUE_OUT_OF_RANGE.
  • No JOIN, aggregates, DDL, NULL, subqueries, arithmetic, or a second interface. Reject with UNSUPPORTED.
  • The owner string is never echoed anywhere.

Research facts every task relies on

  • Console exe via the EXP file. Clarion has no project-level console switch; the subsystem comes from the linker's module-definition file. Every project links a default C:\Clarion12\libsrc\win\clawstd.exp containing NAME CLAWSTD GUI. A file named <OutputName>.exp beside the cwproj replaces it with no project entry needed, and NAME 'tpscli' CUI makes the linker emit a CONSOLE-subsystem exe. Verified by rebuilding the probe: PE subsystem 2 became 3, cmd waited and captured output in order before the exit code, PowerShell captured every line. Stdout is still written with GetStdHandle(-11) + WriteFile (Clarion has no console I/O statements). Reference: Clarion help topic "Module Definition Files (.EXP Files)", NAME statement apptype WINDOWAPI, GUI or CUI.
  • Static link is <Model>Lib</Model>, which pulls ClaRUNl.lib, ClaTPSl.lib automatically. Local is silently ignored. Include paths come from C:\Clarion12\bin\CLARION120.RED, so StringTheory and DynFile need no project entries.
  • Build command (both properties mandatory, exit code is trustworthy): 
    C:\Windows\Microsoft.NET\Framework\v4.0.30319\MSBuild.exe tpscli.cwproj /t:Rebuild /p:Configuration=Release ^
  /p:ClarionBinPath="C:\Clarion12\bin" /p:clarion_version="Clarion 12.0.14000" /v:minimal
  • DFD in a Lib-linked exe: PROP:Driver does not work (error 80). Use DynFile.SetDriver(*FILE) with a static placeholder FILE declared DRIVER('TOPSPEED'). FIXFORMAT only accepts a FILE created with NEW, so a compile-time VIEW cannot sit on it: the executor uses SET/NEXT and EVALUATE, not VIEW. This is a deviation from spec §5 ("VIEW with PROP:Filter") and is recorded in the notes.
  • DynFile contract (read from DynFile.clw): AddField(TFieldGrp) with Label, Type as text ('STRING', 'DECIMAL', 'GROUP'...), Size, Places, Dim, Over, Fields, Picture; AddKey(TKeyGrp) with Type 'K'/'I', Dup, Opt, NoCase, Primary; AddFieldToKey(key, fieldLabel, asc, rank); AddMemo(TMemoGrp) with MemoNbr negative, Type 'M'/'B', Binary, size. FixFormat shows a modal MESSAGE on error (line 842); CreateStruct and rDynF are PROTECTED so a derived class can shadow it. GetField(label) is WHAT(record, n) after matching WHO(record, n) for n in 1..PROP:Fields; array elements are WHAT(record, n, elem).
  • TPS layout (ported from ctrl-alt-dev/tps-parse, Apache 2.0, plus the clarionlife.net format note for flag bits): header 0x200 bytes, magic tOpS at 0x0E, 60 block start/end refs at 0x20 and 0x110 with offset = (ref << 8) + 0x200; pages found by scanning 0x100 boundaries for a self-addressing LE long; 13-byte page header; RLE when pageSize <> pageSizeUncompressed and flags = 0; record headers with 0xC0 flags on the first record and delta reuse after; type byte at header offset 4 (0xFA = table definition, block index LE u16 at offset 5); definition = u16 driverVersion, recordLength, nrOfFields, nrOfMemos, nrOfIndexes then field, memo, index entries. Key flags: 0x01 DUP, 0x02 OPT, 0x04 NOCASE, bits 5-6 type (0 = KEY, else INDEX); 0x10 claimed PRIMARY by two readers, unverified. Per-component flag nonzero = descending. Field entry u16 flags = 1 means OVER, u16 index = field ordinal.
  • Command line: COMMAND(n) returns the n-th argument with quotes stripped; the flag-lookup form is unreliable. Parse with a loop.

tpsOut.Write PROCEDURE(STRING s)
written  ULONG
done     LONG
  CODE
  LOOP WHILE done < LEN(s)
    written = 0
    IF WriteFile(SELF.hOut, ADDRESS(s) + done, LEN(s) - done, written, 0) = 0 OR written = 0 THEN HALT(3).   ! stdout gone: nothing else we can say
    done += written
  END

tpsOut.Line  PROCEDURE(STRING s)

tpsOut.JStr  PROCEDURE(STRING s)
st   StringTheory
i    LONG
c    BYTE
  CODE
  st.SetValue(s)
  st.Replace('\', '\\')
  st.Replace('"', '\"')
  st.Replace('<13>', '\r')
  st.Replace('<10>', '\n')
  st.Replace('<9>', '\t')

      st.SetSlice(i, i, '\u00' & SUB('0123456789abcdef', BSHIFT(c,-4)+1, 1) & SUB('0123456789abcdef', BAND(c,0Fh)+1, 1))

tpsOut.Fail  PROCEDURE(STRING code, STRING msg, LONG exitCode, <STRING extraJson>)
  CODE
  SELF.Line('{{ "ok": false, "op": null, "error": {{ "code": ' & SELF.JStr(code) & ', "message": ' & SELF.JStr(msg) & ' }' |
            & CHOOSE(OMITTED(extraJson) OR extraJson = '', '', ', ' & extraJson) & ', "complete": true }')
  HALT(exitCode)

tpsOut.ReadStdin PROCEDURE()
chunk STRING(4096)
got   ULONG
rc    LONG
  CODE
  IF SELF.StdinRead THEN RETURN SELF.StdinBuf.GetValue().
  SELF.StdinRead = 1
  LOOP
    got = 0
    rc = ReadFile(SELF.hIn, ADDRESS(chunk), SIZE(chunk), got, 0)
    IF rc = 0
      IF GetLastError() = 109 THEN BREAK.                 ! ERROR_BROKEN_PIPE = clean EOF on a pipe
      SELF.Fail('SYNTAX', 'Reading stdin failed (' & GetLastError() & ')', 1)
    END
    IF got = 0 THEN BREAK.
    SELF.StdinBuf.Append(chunk[1 : got])
  END
  RETURN SELF.StdinBuf.GetValue()

ParseArgs  PROCEDURE()
n     LONG
a     &STRING
seen  BYTE
  CODE
  LOOP n = 1 TO 4096                  ! COMMAND(n) returns '' past the last argument, which ends the loop; 4096 is a guard, not a cutoff
    a &= NEW STRING(LEN(CLIP(COMMAND(n))))
    a = COMMAND(n)
    IF a = '' THEN DISPOSE(a); BREAK.
    IF n = 4096 THEN Out.Fail('SYNTAX', 'Too many arguments', 1).
    CASE LOWER(CLIP(a))
    OF '--owner'
      n += 1
      Opt.Owner = COMMAND(n)
      IF Opt.Owner = '' THEN Out.Fail('SYNTAX', '--owner needs a value', 1).
    OF '--table'          ; Opt.Table = 1
    OF '--parse-only'     ; Opt.ParseOnly = 1
    OF '--limit-default'
      n += 1
      IF NOT MATCH(CLIP(COMMAND(n)), '^[0-9]{{1,10}$', Match:Regular) OR COMMAND(n) > 2147483647
        Out.Fail('SYNTAX', '--limit-default needs a non-negative integer up to 2147483647', 1)
      END
      Opt.LimitDefault = COMMAND(n)
    OF '--version'
      Out.Line('{{ "ok": true, "op": null, "version": "' & TPSCLI_VERSION & '", "complete": true }')
      HALT(0)
    ELSE
      IF SUB(a, 1, 2) = '--' THEN Out.Fail('SYNTAX', 'Unknown option ' & CLIP(a), 1).
      IF seen THEN Out.Fail('SYNTAX', 'Only one statement per invocation', 1).
      seen = 1
      Opt.Sql &= a; a &= NULL; CYCLE
    END
    DISPOSE(a)
  END
  IF NOT seen
    Opt.Sql &= NEW STRING(LEN(CLIP(Out.ReadStdin())))
    Opt.Sql = Out.ReadStdin()   ! second call returns the buffered copy, see tpsOut.ReadStdin
  END

    tpsSchema.DeRle PROCEDURE(LONG o, LONG clen, StringTheory outp)
p     LONG
endo  LONG
skip  LONG
msb   LONG
rep   LONG
cnt   LONG
  CODE
  p = o; endo = o + clen
  LOOP WHILE p < endo
    skip = SELF.U8(p); p += 1
    IF skip = 0 THEN RETURN 0.
    IF skip > 7Fh
      IF p >= endo THEN RETURN 0.
      msb = SELF.U8(p); p += 1
      skip = BAND(BSHIFT(msb, 7), 0FF00h) + BAND(skip, 7Fh) + 80h * BAND(msb, 1)
    END
    IF p + skip > endo THEN RETURN 0.
    outp.Append(SELF.buf[p+1 : p+skip]); p += skip
    IF p >= endo THEN BREAK.

    cnt = SELF.U8(p); p += 1

      IF p >= endo THEN RETURN 0.

      cnt = BAND(BSHIFT(msb, 7), 0FF00h) + BAND(cnt, 7Fh) + 80h * BAND(msb, 1)
    END

  END
